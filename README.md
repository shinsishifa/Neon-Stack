# 🗼 Neon Stack — HTML5 Arcade Stacking Game

**Neon Stack** is a vibrant, retro-futuristic arcade stacking game built natively with HTML5 Canvas and Vanilla JavaScript. Test your timing and precision as you build a glowing neon tower toward the digital sky.

---

## 🌟 Key Features

* **Zero Dependencies:** Pure HTML5, CSS3, and JavaScript with smooth 60 FPS animations.
* **Dynamic Camera Scrolling:** The game world shifts upward seamlessly as your tower grows taller.
* **Progressive Difficulty:** Moving block speeds increase incrementally with every successful level.
* **Persistent High Scores:** Automatically records and saves your top score using the browser's `localStorage`.
* **Cross-Platform:** Optimized for desktop keyboard controls (`Spacebar`) and touch screen tapping.
